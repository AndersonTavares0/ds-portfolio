Retail Analytics Portfolio

End-to-end data science on a real Brazilian marketplace

The narrative

In this marketplace, delivery performance drives customer satisfaction and retention. I measured it, I predicted it, and I explained the voice of the customer.

Three projects built on the same Olist Brazilian E-Commerce dataset — ~100,000 orders across nine related tables. Each project ships a report, a one-page decision memo, and an honest statement of what the data cannot support.

Projects

01 · Retail Analytics · published

Question. Which levers actually move customer satisfaction and repeat purchase?

RFM segmentation, monthly cohort retention, and a decomposition of delivery performance — modelled with dbt on top of PostgreSQL, with data tests that fail the build when the data stops making sense.

PostgreSQL · dbt · SQL · Python · Quarto

Read the report Decision memo

02 · Late-Delivery Prediction · in progress

Question. At purchase time, can we tell which orders will arrive late?

A cost-sensitive classifier that is honest about leakage: only features available at the moment of purchase are allowed in.

Python · pandas · scikit-learn

03 · Voice of the Customer · planned

Question. What do ~99,000 Portuguese-language reviews actually complain about?

Sentiment and topic modelling — with the finding that the complaints are about logistics, not products, which closes the argument opened in Project 01.

Python · NLP · topic modelling

How this is built

Every project in this repository is reproducible from a clean clone:

uv run python tasks.py setup      # dependencies + database + dataset
uv run python tasks.py pipeline   # load -> dbt build -> tests -> render

The dataset is downloaded from a revision-pinned mirror and validated against expected file sizes, so the numbers in these reports do not quietly change underneath you.
